以已落实教师意见的三份修订稿为依据，保留 21 个关系和 3 个业务视图。分阶段计划是实施顺序，本文件是阶段 1 的详细操作契约与验收清单。当前前端原型和业务 API 不在本轮范围内。

核对报告后明确：首次创建计划必须同时创建版本 1 并标为当前；草稿修改产生新的当前草稿。已确认计划的候选版本在确认前不改变当前安排；执行中只允许调整计划离泊时间，保留 EXECUTING 和原执行基准。锚地属于港口，不属于码头；排队取消不等于实际离锚。

## 操作契约

全部公共写过程要求有效且启用的操作人；同时验证其角色启用。API 身份鉴别与角色授权在后续阶段实现，数据库操作人参数不等同于可信登录身份。过程采用 XACT_ABORT、TRY/CATCH、显式事务；失败回滚整个工作单元，包含调用者外层事务，调用者不可在失败后提交残余操作。禁止动态拼接业务 SQL。

为单港课程演示采用一把事务级应用锁 PortQueue.Schedule，串行化七个写入口。锁超时明确失败；多表读写和审计提交保持原子性。这是当前规模下易验证的并发策略，将来有实测吞吐瓶颈再细化到锚地或泊位锁。

| 操作 | 输入与前置条件 | 原子动作与成功结果 | 失败结果 |
|---|---|---|---|
| 审核预约 | 待审核预约、操作人、APPROVED/REJECTED；驳回原因非空 | 写审核信息与前后快照，返回预约主键与状态 | 不存在、重复审核、空决定、无效操作人拒绝 |
| 登记锚地进出 | 已批准预约、锚地、类型、非未来事件时间 | 进入按优先级降序、时间升序、主键升序确定插入点，已有人工顺序保留；离开后补齐序号；事件和分类同时写入 | 重复进入、容量不足、错误锚地、时间倒置拒绝；取消但仍在场允许离开 |
| 人工调序 | 有效队列主键、目标位置、非空原因、操作人 | 保存全部受影响行的前后位置，队列为 1..N，写审计 | 越界、无效队列、原位置重复提交拒绝且不留调整记录 |
| 创建版本 | 预约、泊位、起止时间、原因、操作人 | 无计划时原子创建计划和当前版本 1；草稿阶段更新当前草稿；已确认/执行中创建非当前候选；返回计划、版本与版本号 | 未批准、终态、时间错误、执行中改泊位或靠泊时间拒绝 |
| 确认版本 | 计划、未确认候选、操作人 | 校验资源、船型、尺寸、吃水、载重吨与半开时间窗；切换当前版本；执行中保持状态；更新在场队列 ASSIGNED | 重复确认、历史回切、版本错属、重叠冲突拒绝，旧当前保留 |
| 实际进港 | 已批准预约、事件时间、操作人 | 写公共事件与进港关联，更新到访执行状态 | 重复或未离锚、早于离锚时间拒绝 |
| 靠泊/离泊 | 已进港预约、类型、事件时间、执行版本、操作人 | 靠泊取事件发生前最后确认的适用版本；离泊沿用同一版本；完成时预约/计划/到访一起结束 | 重复、未来时间、事件顺序错误、执行基准错配拒绝 |

队列移动采用事务内暂存到无冲突的正数区间后写回 1..N，避免 SQL Server 唯一索引在换位时冲突；不禁用索引。自动入队和离队留下队列审计，人工调序另外写 queue_adjustment_record，避免把自动补位误称为人工调整。

## 历史与审计

审计由每个业务过程在同一事务中追加，直接使用 inserted/deleted 快照或事务前后 JSON；包含操作人、对象主键、变更前后值，事件快照包含分类关联。不记录密码散列，不以审计快照替代业务表。审计失败则业务失败。追加保护触发器拒绝 UPDATE/DELETE；应用角色也无写审计权限。

字典类型和代码一经建立不可修改，可改显示名称或停用；停用保留已有引用，重新启用泊位船型关系必须检查字典启用状态。已有 6 个业务触发器增加字典标识保护和审计追加保护 2 个表级触发器，数量不是评分目标。

## 权限与演示数据

- 创建 portqueue_app 数据库角色，仅授予明确的视图/查询列 SELECT 与七个业务过程 EXECUTE，不授予 schema 级 EXECUTE，不可直接增删改业务表。
- 用 WITHOUT LOGIN 用户验证角色权限；它不能作为 API 的连接账号。LocalDB 的当前所有者是管理员，仍有高权限；后续普通 Windows 服务账号通过管理员显式映射，不用仓库密码创建 SQL 登录。
- 参考种子重复执行不重新启用已停用资料，不保存固定演示密码。
- 演示数据独立装载，命名空间 PQ-DEMO-*；包含完成的锚地路径、完成的直靠路径、待审核预约和在场队列。历史时间为明确的样例事实，固定 UTC 时间，重跑保留业务进度且不重置。
- 验收使用新建的专用测试库，前缀 PortQueueStage1Test_，不清空开发库。负向用例单独事务，结束核对无残留；并发用例使用两个独立 SQL 连接。
