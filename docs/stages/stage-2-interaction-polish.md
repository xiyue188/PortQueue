# 查询交互与工作台稳定性

日期：2026-11-08。第三阶段仅规划。本批只修改既有前端与浏览器验收，不改后端、数据库结构、权限或业务数据。

## 设计

- 搜索获得焦点时通过既有预约 API 提供最多六条真实候选；输入防抖、取消旧请求，支持鼠标、方向键、Enter、Escape 和中文输入法。不输入完整编号也可选择；自由查询仍可提交。
- 总览预约摘要与预约检索分开保存状态。首次进入预约页才加载，随后切换复用状态；总览全局指标一直独立，返回总览不重建页面。浏览器前进/后退支持两个页面。
- 查询时保留已有列表和选中详情，在结果区显示局部加载状态并暂时阻止操作旧结果。新结果成功后替换；失败明确显示错误并清除失效结果。分页标签/筛选状态以已完成结果为准，避免把旧结果冒充新条件。
- 桌面两页共享固定视口外框、侧栏、工具栏、摘要高度和主次栏比例。内容在各自区域滚动；窄屏自然纵向布局，表格局部横向滚动。减少动态偏好禁用过渡。
- 保留冰蓝商务风格与一处波浪细节，减轻双层高亮边框、重复圆角卡片和过强阴影；概要信息改用整齐分隔行，提高层次和清晰度。

## 验收

| 编号 | 条件 |
|---|---|
| I01 | 无输入可选择真实预约；部分船名可联想；选择后查询对应预约，保留自由搜索 |
| I02 | 候选键盘导航、Escape、点击外部、IME、无匹配、网络失败与旧请求取消可用 |
| I03 | 重复切换两页不产生额外预约请求；过滤/分页及选中记录保留；浏览器返回可用 |
| I04 | 刷新、筛选、翻页期间原表格 DOM 保留，滚动/外框不跳动，加载提示可见；失败不显示过期记录；快速连续提交关键词/状态时合并最近已提交条件 |
| I05 | 同一桌面视口两页外框/侧栏边界及主要列比例一致；1440、用户截图2470和973参考宽度均检查 |
