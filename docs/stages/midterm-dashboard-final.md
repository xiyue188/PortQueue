# 中期看板与全状态筛选收口

日期：2026-11-10。仅完善现有总览和预约页面；后续模块继续待接入。

## 设计

- 保留冰蓝布局及主图四入口。流程图内容在面板有效空间中居中，节点各自中心对齐；桌面横向、窄屏纵向。
- 按用户船形参考，用项目 SVG 线条绘制小船，不使用带水印的图片。小船沿流程连线移动，表达业务方向，不表示真实船舶或 AIS。可暂停；离开总览、屏外、浏览器后台及减少动画偏好时停止。不增加动画库。
- 总览每 30 秒读取最新数据库快照；本页写入完成立即刷新。后台/离开总览停止轮询，返回时仅在数据过期后刷新。沿用请求取消与序列保护，不重建页面，不重置港口动态分页；失败清除失效数值并可重试。
- 清单提供全部、草稿、待审核、已批准、已驳回、已撤销、已完成七个入口，复用统一状态定义，移除重复下拉框。窄屏换行，不隐藏状态。
- 三指标保持既有业务口径，提供按需可读的口径提示；不增加装饰性数字。登记入口继续受真实账号权限控制。

## 验收条件

| 编号 | 场景 | 通过条件 |
|---|---|---|
| D01 | 居中与动效 | 桌面节点中心、轨道端点对齐；整体居中，窄屏无溢出；小船确实移动，可暂停，减少动画/隐藏/离开页面停止 |
| D02 | 看板刷新 | 30秒自动发起真实查询；旧请求不覆盖新结果；后台与离页停止；返回仅过期才刷新；动态页码不被重置 |
| D03 | 六状态 | 七个按钮都可见，按 API 真实数量和状态核对；草稿、驳回、撤销可直接筛选，零记录仍保留入口 |
| D04 | 页面新增 | 独立测试库中由调度员通过页面新增、编辑、提交并由审核员审核；数据库及总览同步，开发库不产生测试记录 |
| D05 | 指标解释 | 待审核=PENDING预约；在场=入锚非空且离锚为空；待靠泊=CONFIRMED当前计划；不相加、不解释成今日量或实时AIS |
| D06 | 交付 | 前端构建、相关完整浏览器回归、既定构建/SQL检查、独立视觉审查；中文小提交与文档；保留用户已启动服务，不新增遗留服务 |

本轮开始时用户已有 API 77424（5180）和 Vite 79860（5173），只复用、不得结束。写入测试仍使用独立随机库与临时5280，结束清理。30秒是本地数据库快照刷新频率，外部实时航运数据未接入；基础资料新增页面不在中期范围。
