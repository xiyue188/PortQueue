# 5A 泊位排期：设计原型与验收

2026-11-28。执行已选A业务任务型：泊位资源时间轴为主、到访详情为辅。本文保留先行HTML原型的设计与验证；用户认可后，同日已完成5A真实查询及正式泊位入口，见[实施记录](stage-5-implementation.md)。下面原型测试结果不替代正式查询验收，正式写操作仍按5B—5D依次实施。

## 业务口径

- 人工预计靠泊：调度员对一段锚地停留的可空判断；无资源分配、不占窗口，不能用它计算正式计划偏差。可作表单初值，不能作为查找可用时段的最早时间限制。
- 计划靠泊：有效已确认版本的时间，关联具体泊位及计划离泊；有计划优先显示，人工预计仅在“候泊参考”中按需查。二者不复制、不自动同步，也不要求都填。
- 草稿/候选不等于已确认。有旧确认版本时，新候选先并列预览，旧安排继续有效。确认取消后不能偷偷恢复为旧人工预计的正式承诺。
- 实际靠泊来自事件，不能因为计划时间已到就自动标为执行中。执行中未离泊仍占用资源，预计结束已过不能显示为空闲。

## 本批设计与文件

原型位于`docs/design/berth-prototype/`。`index.html`定义语义骨架与表单，`prototype.css`继承冰蓝外框并表达资源时间轴，`scenarios.js`集中可核查的合成资料和固定参照时刻，`prototype.js`处理选择、视窗、拖动、校验及页面内候选。不开新依赖、不复制后端业务引擎。图片复用已有port-scene素材，不作为实船照片。

首屏：左侧公共导航，顶部日期/区间；主区每泊位一行、时间按比例横排；右侧突出所选到访与当前安排；下方显示待安排到访供选择。导航至未接入页面有明确反馈。设计说明集中在“交互原型”入口，不堆解释性小字。无伪造登录账号。

交互：点击船舶或时间条查看；拖动条身横向改时、纵向换泊位，15分钟吸附，保留旧位置轮廓；落下后表单显示旧新安排、冲突对象和具体原因。编辑安排可独立使用，时间精确到分钟；取消/Esc不改原值，应用仅存当前页面候选，刷新重置。图形浏览支持横滚，窄屏切“明细”；24/48小时范围、日期前后、回到参照时刻、搜索选船不隐藏其他计划。

## 验收用例

| 用例 | 观察结果 |
|---|---|
| 时间比例/跨日 | 同一视窗1小时宽度相等，2小时宽度为两倍；跨日完整、边界截断明确 |
| 待安排→选泊位→候选 | 带入同一到访资料与作业时长；保留其他安排；形成候选不冒称确认 |
| 已确认→拖动→取消/应用 | 取消保持原安排；应用后旧确认条仍在，候选不占正式窗口 |
| 冲突/适配 | 重叠给出船名与时段；相接允许；船型/吃水/船长/吨位给具体限制 |
| 实际超时/已完成 | 已靠泊未离泊继续占用；不因计划结束释放；已完成只读 |
| 单击/精调/键盘 | 单击不改时；拖动有阈值；表单分钟不强制整刻；Esc取消；按钮有名称与焦点 |
| 长轴/窄屏 | 1440×900、1366×768、1920×1080、390/320px；主任务可达、内容不越界、拖动可到屏外资源 |
| 日期/搜索/空区间 | 查询选择与全局资源分开；无计划日期正确显示空态；清除搜索恢复候选 |
| 安全边界 | 无API写请求、无真实授权模拟；浏览器控制台无错误，刷新无持久业务改动 |

使用仓库Playwright、本机Edge与本地HTML验证（当前无Browser插件）。截图在忽略的artifacts目录，确认后更新正式设计截图；review记录结果而不把原型当成真实业务。

2026-11-28执行结果：16项本地HTML浏览器任务通过，另1项现有Vite入口/素材/操作验证通过；原有前端构建、原型JS语法和29份SQL静态解析通过。覆盖鼠标条身/把手、触摸、横纵移动、取消/Esc、分钟输入、跨日比例、多个候选并存、冲突、次日未释放占用，以及1440×900、1366×768、1920×1080、390/320px。真实API、权限、并发与跨页恢复尚未在5A接入。

独立设计审查指出持续占用随原计划消失、操作被详情挤出两项；已增加独立未释放底带/明细与固定操作区，窄屏提供图前办理入口，复核均resolved。未知结束不等于预测持续到视窗末端；原型保守地不提供该泊位新候选，真实接入须再明确“延期后可预测窗口”规则。正式截图见[桌面](../design/stage-5a-berth.png)、[窄屏](../design/stage-5a-berth-mobile.png)，详细结论见[review](../reviews/2026-11-28-stage5a-berth.md)。
