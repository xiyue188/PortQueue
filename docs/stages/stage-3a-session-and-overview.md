# 阶段 3A：身份权限与总览职责收口

日期：2026-11-09。状态：本批实现与验收完成，独立审查通过。承接阶段 2 的真实只读链路；下一批进入 3B 审核，第三阶段整体尚未完成。证据见 [阶段 3A review](../reviews/2026-11-09-stage3a-review.md)。

## 问题与取舍

旧总览使用最近五条预约同时驱动单船轮播、审核摘要和小清单，既无法覆盖所有状态，也重复预约页职责。删除单船轮播与重复清单；沿用冰蓝布局和场景图，改成跨业务概要。不通过扩大轮播条数继续增加重复内容。

## 实施范围

1. 总览：保留三个主指标；展示全量六状态分布、有效锚地队列（等待/已分配）、当前泊位计划（草拟/已确认/执行中）及累计实际事件。状态点击进入对应预约筛选；未实现业务页面仍不开放假入口。概要来自已有表和三个视图，不创建表。
2. 身份：GET /api/session、POST /api/session/login、POST /api/session/logout；标准 PasswordHasher、HttpOnly Cookie、防伪造令牌和每来源每分钟五次登录尝试限制。正常只读匿名访问沿用阶段 2。
3. 权限：ADMIN/DISPATCHER 可登记提交；ADMIN/REVIEWER 可审核；RECORDER 只读。策略真实注册，业务写端点在 3B/3C 才接入；权限测试用仅测试程序集的探针，产品不增设假业务接口。
4. 每次带认证 Cookie 的请求复核账号、角色启用状态和密码指纹。停用或改密码撤销旧身份；角色变更即时刷新授权。Cookie 为非持久会话，最长八小时，不使用 localStorage 保存凭据。
5. 账号用本机受控管理命令创建、设置密码、启停；显式事务并写不含密码/哈希的审计。现有样例操作人保持不可登录，不给其设置默认密码。管理命令只由有数据库管理权限的本机用户执行，应用数据库角色仍禁止直接写表。
6. 前端账号区显示真实姓名、中文角色、登录/退出；登录框有明确字段、失败反馈、键盘焦点和窄屏适配，不添加预约写入占位按钮。

## 数据和文件边界

SQL 先更新 overview.sql，并新增 account.sql 和 manage-account.sql。09_permissions.sql 增加认证所需账号和角色列读取；不增加业务过程或关系。Infrastructure 执行维护 SQL；Application 定义账号契约；Api 管理认证、授权和本地控制台入口。前端 PortOverview 只负责全港概要，SessionAccount 负责会话 UI；清单与独立详情继续沿用原链路。必要中文注释说明责任与边界。

## 验收条件

| 编号 | 用例 | 必须结果 |
|---|---|---|
| O01 | 总览读取 | 无预约列表请求；六状态含零值且和等于预约总量，与逐状态查询一致 |
| O02 | 点击已批准/其他状态 | 进入对应完整清单，真实总数与状态正确；不存在轮播前五条限制 |
| O03 | 队列/计划/事件概要 | 与现有视图统计一致，区分在场数与有效队列，不把累计量说成今日量 |
| A01 | 正确/错误/未知/占位哈希账号 | 正确登录，其余统一 401；无密码或哈希泄露；哈希编码在 256 字节内可往返 |
| A02 | 缺少/错误防伪造令牌 | 登录和退出均 400，正常同源令牌可用，登录前后更新令牌 |
| A03 | 权限与失效 | 匿名 401、错角色 403、正确角色通过；停用账号/角色、改密码后拒绝旧会话；改角色下一请求生效 |
| A04 | 连续尝试/退出 | 第六次返回 429；退出后 session 无身份且受保护请求 401 |
| A05 | 账号维护 | 创建/重置/启停可用，重复创建拒绝，密码不进日志/审计，最小权限账号不能直接维护 |
| U01 | 浏览器 | 登录失败保留用户名、不显示密码；成功真实姓名角色、刷新保持、退出恢复；390/320 不溢出，Esc/焦点可用 |
| Q01 | 收口 | 构建、真实 SQL/API 集成、SQL 解析、浏览器验收、深度 review、中文小步提交和文档 |

## 本轮不做

不实现预约审核/登记写入，不接 AIS/地图，不增加企业级认证服务、权限表或分布式组件。登录限速为单进程开发部署边界；上线多实例需另行设计。会话退出清除当前浏览器 Cookie，管理员停用/改密码可使所有旧会话失效。
