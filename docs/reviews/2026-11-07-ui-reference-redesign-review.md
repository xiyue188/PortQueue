## 发现与修正

1. 窄屏中，表格表头的屏幕阅读器辅助文字采用绝对定位，定位基准越过表格滚动容器，导致文档宽度增加。滚动容器增加定位上下文后，辅助内容仍保留，无需隐藏整页溢出。
2. 故障测试最初使用过宽 URL 通配符，误拦截 Vite 的 `src/api/appointments.ts` 模块，页面没有挂载。改为精确匹配 `/api/appointments` 路径，真实错误组件与重试测试通过。
3. 首轮独立视觉审查指出主图矩形接缝、时间窗左端白字对比不足。照片改为连续满铺，底部暗层置于横向浅层之上，桌面和移动端一起修正。
4. 审查指出清单、详情和外层背景过于接近。调整工作区为更深的冰蓝，清单使用浅冰蓝玻璃，详情使用更亮的蓝白玻璃，保留细白边和蓝色行选中态。
5. 产品与运行文档中仍有“静态总览”“浏览器验收待补”的旧描述。已按真实实现和本次证据同步修订，新增设计规范与浏览器运行说明。
6. 后端回归构建首次遇到运行中的本项目 API 锁定输出 DLL。确认进程路径后仅停止该 API，正常构建/测试通过后恢复服务；无需重启系统或修改数据库。
