|---|---|

| 指标口径 | 锚地在场按实际进出事件还原；等待/已分配来自有效队列；草拟/已确认/执行中来自当前计划；进港/靠泊/离泊标明累计，不冒充今日或实时 AIS |

| 请求与错误恢复 | 保留查询草稿/已提交条件、取消旧请求和序列校验；失败清除无效身份或结果，登录校验失效可恢复 |
| 既有业务 | 未更改业务表、视图、过程或触发器结构；仍为 21 张基本表、3 个业务视图、7 个业务过程、8 个表级触发器 |

## 4. 已知边界与未验证项

1. 匿名只读查询继续保留，预约写操作尚未开放。当前角色策略的授权探针只存在测试程序集，不部署假业务端点。
2. 登录限速为单进程、按服务看到的来源地址计算。当前 Vite 同源代理的请求可能共享来源配额；未配置外部反向代理、多实例共享限流或开放公网部署。
3. Cookie 非持久化、绝对八小时、不滑动续期。退出清除当前浏览器 Cookie；停用账号或改密码可以拒绝所有旧会话。没有新增集中式会话存储。
4. 当前账号引导由本机数据库管理身份执行。审计的关联账号使用目标账号，JSON 明确保存 `ORIGINAL_LOGIN()` 作为实际数据库操作者；不能将此等同于未来由登录管理员发起的账号管理页面。
5. 本轮没有在开发库创建可登录账号，也没有默认密码。用户通过交付说明中的本机命令自设密码；截图验收账号不能直接用于开发库登录。
6. 已验收 Edge 桌面与 320/390px 等浏览器视口。未验收真实移动设备软键盘、Safari/Firefox、读屏器、多实例部署和生产 HTTPS 环境，不将视口测试称为这些环境均已通过。
